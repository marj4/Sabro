
# Project Instructions

## Project
This repository contains a website with separate frontend
and backend codebases.

## General Rules
- Follow existing architecture and conventions.
- Make only changes relevant to the task.
- Never rewrite working code unnecessarily.
- Avoid introducing dependencies without justification.
- Keep code maintainable and secure.

## Context Efficiency
- Inspect only files relevant to the task.
- Avoid unnecessary repository-wide searches.
- Do not repeat unchanged code in responses.
- Keep explanations concise.
- Do not create documentation unless requested.

## Responsibilities
- Frontend code belongs in frontend/.
- Backend code belongs in backend/.
- Respect the instructions in each directory.
- Coordinate API contracts through explicit interface definitions.

## Verification
- Run relevant checks when possible.
- Report changes and errors briefly.
